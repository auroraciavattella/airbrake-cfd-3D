# CFD Analysis of a Rocket Airbrake System — 3D Model

This repository contains the OpenFOAM case developed for the three-dimensional
aerodynamic characterization of a cassette-type airbrake system mounted on the
cylindrical body of a student-built sounding rocket ("Atlas", Aurora Rocketry).

Airbrakes are movable surfaces that, during the coast phase of flight, are
progressively exposed to the flow to increase the vehicle's aerodynamic drag.
The resulting variation in drag can be used within an active apogee control
system.

This 3D model extends a preliminary quasi-two-dimensional characterization
(see the companion 2D repository) by representing the finite width of a
single airbrake panel and its interaction with the rocket body, exploiting
the periodicity of the three-panel system.

## Numerical model

The system consists of three identical rectangular airbrake panels, spaced
120° apart around the rocket body. Assuming symmetric flow conditions, the
computational domain is reduced to a single 120° periodic sector containing
one panel, with the two lateral faces (`front`, `back`) treated as symmetry
planes.

Two opening configurations were simulated: **40%** and **100%** of the
maximum panel deployment height.

Main simulation settings:

- **software:** OpenFOAM v2506 (ESI/OpenCFD);
- **solver:** `simpleFoam`;
- **regime:** steady-state, incompressible;
- **turbulence model:** RANS k–ω SST;
- **freestream velocity:** 100 m/s;
- **domain sector angle:** 120°;
- **maximum airbrake deployment height:** 0.05 m;
- **mesh generator:** `blockMesh` + `snappyHexMesh` (native OpenFOAM
  meshing, unlike the Gmsh-based wedge mesh used in the 2D model).

A prismatic boundary layer was applied to the combined rocket-body/airbrake
wall (`rocketAirbrake` patch): 15 layers, first layer height
2.633×10⁻⁵ m, growth ratio 1.2, matching the 2D case for direct
comparability. Because the mesh is unstructured, the number of layers
actually grown is not perfectly uniform (on average ≈13.2 of the 15
requested layers, ≈95% of the nominal boundary-layer thickness).

## Objectives of the analysis

The simulation allows to:

- compute the aerodynamic forces acting on the rocket body and on the
  airbrake panel;
- determine the drag coefficient of the full three-panel system from a
  single periodic sector;
- analyze the velocity and pressure fields around the panel;
- observe flow separation and wake formation downstream of the airbrake;
- evaluate the y⁺ distribution on the wetted surfaces, by zone (panel,
  body, nose, tail);
- correlate the 3D results with the preliminary 2D model to derive a
  correction factor (K₃D) usable in a control-oriented lookup table.

## Repository structure

The repository contains the OpenFOAM case for the 100% opening
configuration. The 40% configuration was generated by re-running the same
meshing and simulation pipeline on a different STL surface (see below),
obtained by changing the `H_airbrake` parameter in the parametric Gmsh
geometry.

- `0/`: initial and boundary conditions for the flow fields;
- `constant/`: fluid properties, turbulence model settings, and the
  `triSurface/` STL geometry used by `snappyHexMesh`;
- `system/`: mesh generation dictionaries (`blockMeshDict`,
  `snappyHexMeshDict`), numerical schemes, solver settings, and the
  `forceCoeffs` function object used to compute C_D;
- `gmsh/`: parametric geometry script used to generate the STL surfaces.

the large size of the mesh files (≈2.3 million cells).
